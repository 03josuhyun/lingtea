# React를 활용한 링티 리뉴얼 사이트

## 프로젝트 소개
### 📋 기획의도
복잡한 건강정보를 쉽게 직관적으로, 링티를 일상 속에서 자연습럽게 경험할 수 있도록!!
기존 링티의 건강하고 활기찬 브랜드 이미지를 유지하면서, 제품과 브랜드 정보를 보다 쉽고 직관적으로 전달하는 사용자 중심의 쇼핑몰로 리뉴얼합니다.
